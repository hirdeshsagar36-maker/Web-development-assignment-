01-url-to-page.mdAssignment 1: What Happens Between Typing a URL and Seeing the Page?

When I type a URL into my browser and press Enter, several steps happen:

1. URL Entry: The browser receives the website address.
2. DNS Lookup: DNS translates the domain name into an IP address to locate the server.
3. Connection: The browser connects to the server. For HTTPS, TLS helps encrypt the communication.
4. HTTP Request: The browser sends a request to the server for the webpage.
5. Server Response: The server sends a response containing the HTML document.
6. HTML Parsing: The browser reads the HTML and builds the DOM (Document Object Model).
7. Loading Resources: The browser loads CSS, JavaScript, images, and other resources.
8. Rendering: The browser calculates the layout and displays the webpage on the screen.

Conclusion: The browser and server work together to turn a URL into a webpage that we can see and interact with.
